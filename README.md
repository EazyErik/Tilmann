# THI – Direkter Ankauf von Immobilien

Statische Website (HTML, CSS, JavaScript) – ohne Build-Schritt.

## Struktur

```
index.html          Startseite
impressum.html      Impressum (Platzhalter ergänzen)
datenschutz.html    Datenschutzerklärung (Platzhalter ergänzen)
assets/main.js      Mobile Navigation und Kontaktformular
assets/img/         Logo und Fotos
```

## Lokal ansehen

`index.html` im Browser öffnen oder `npx serve .` ausführen.

## Offene Punkte

- Platzhalter in eckigen Klammern (z. B. `[ANSCHRIFT]`) in Impressum und Datenschutz ersetzen.
- Kontaktformular an einen Versanddienst oder ein Backend anbinden (siehe `TODO` in `assets/main.js`).
- Fotos durch hochaufgelöste Originale ersetzen (gleiche Dateinamen in `assets/img/`).
- Schriften werden von Google Fonts geladen; für DSGVO-Konformität ggf. lokal einbinden.
